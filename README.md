# AI Buddy UI

为 AI Buddy 提供后台运维，包括供应商、模型、默认对话/向量/绘画模型、快捷短语、助手、专家、MCP、技能包、知识库与文档、子代理，以及搜索配置

## 插件类型

- 前端插件

## 配置说明

无需额外环境变量或前端运行时配置

安装前请确保后端 AI Buddy 插件已启用，并已完成对应菜单和权限配置

## 使用方式

1. 安装并启用后端 AI Buddy 插件和前端 AI Buddy 插件
2. 在系统中进入 AI Buddy 相关菜单
3. 维护内置供应商、模型、默认对话/向量/绘画模型、快捷短语、助手、专家、MCP、技能包、知识库与文档、子代理和搜索配置；先配置默认向量模型再创建知识库
4. 在模型服务页面同步全部平台模型架构，通过消息查看更新和跳过数量；同步包含已禁用的供应商和模型
5. 超级管理员在 MCP 列表的 HTTPS 远程内置 MCP 上打开“配置 OAuth”，维护平台客户端配置；回调地址由后端 `AI_BUDDY_MCP_OAUTH_REDIRECT_URI` 提供，后台只读展示并支持复制，需在服务商登记相同地址
6. 通道绑定和对话定时只在客户端完成

## 卸载说明

- 卸载插件后，建议同步移除 AI Buddy 相关菜单和权限
- 如业务流程已依赖 AI Buddy 能力，请同步清理对应集成
